# JReleaser publisher

This module integrates with JReleaser.

This publisher is **available with dedicated extension** (due JReleaser size).

* Publisher ID: `jreleaser`.
* Configuration source: `jreleaser.yml` (is mandatory)
* Configuration:

| Configuration key               | Default value  |
|---------------------------------|----------------|
| `njord.jreleaser.yolo`          | `false`        |
| `njord.jreleaser.dryRun`        | `false`        |
| `njord.jreleaser.gitRootSearch` | `false`        |
| `njord.jreleaser.strict`        | `false`        |
| `njord.jreleaser.reproducible`  | `false`        |
| `njord.jreleaser.command`       | `FULL_RELEASE` |
| `njord.jreleaser.reproducible`  | `false`        |
